campello_audio — WASM Example

This example demonstrates the WebAssembly backend using the Web Audio AudioWorklet API. Click Start Audio to initialize the audio engine and play a 440 Hz sine tone.

Note: Browsers require a user gesture (button click) to start an AudioContext. The page must also be served with Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp headers for SharedArrayBuffer / pthread support.
